Before you start

Four rules remove almost every ambiguity.

01

Heights from the base

Every height is measured from the top surface of the white base plate, not from the table.

02

Front is the sticker side

The front face carries the Pakaon AI sticker and the black controller panel.

03

Width and depth

Width is left-to-right facing the front. Depth is the front edge to the rear edge.

04

Blank is allowed

If the tape cannot reach it, leave it blank. The export lists what is missing.

Reference drawings

Schematic and not to scale. The reference column repeats each callout.

Export

JSON is the preferred format: it keeps the field IDs, labels, missing values and notes together. The compact text is a fallback for chat.

JSON

The exact file the model rebuild reads. It includes a self-describing label for every filled field and lists anything missing.

Compact text

One ID=value per line, with a missing-field summary. Easier to paste into a message; less structured than JSON.

Print

Print the filled sheet as a record of the physical measurement. The browser's print dialog can also save it as a PDF.
