### Owner: firmware 1.10.0 release (#582)

`FW_VERSION` is bumped `1.9.0 → 1.10.0` in PR #598. Signing is **blocked on the offline private
key** — `scripts/ota/sign-release.mjs` runs on Jeff's machine only, and only the public PEMs are in
the repository. Steps, in order:

1. Confirm the field unit is physically wired to **GPIO 5**.
2. Sign:
   ```bash
   node scripts/ota/sign-release.mjs \
     --bin firmware/.pio/build/esp32dev-gpio5/firmware.bin \
     --version 1.10.0 --variant gpio5 --env esp32dev-gpio5 \
     --key ../ota-signing-keys/pakaonai-ota-primary-private.pem \
     --key-id primary --min-from 1.10.0 --targets all --out ota-out
   ```
3. Upload the binary to `releases/1.10.0/firmware.bin` and the generated channel to
   `channels/stable.json` in the private `firmware` bucket.
4. Bootstrap the field unit over USB **once** with `-e esp32dev-gpio5`. Pre-1.10.0 firmware sends
   no variant, so the new check endpoint answers `{update:false}` until then.

Until step 3 is done the live channel has no `variant` and the new parser rejects it — fail-closed,
so no unit is offered a wrong-pin image, but no unit is offered anything either.
