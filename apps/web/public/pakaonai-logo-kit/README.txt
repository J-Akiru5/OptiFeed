PakaonAI logo kit

color            Closest match to the original image. Exact vector outline, filled with the
                 original's own smooth gradient shading (embedded inside the SVG). Opens in
                 browsers, Figma, Illustrator and Inkscape. The outline scales without limit;
                 the shading is a smooth image, so gradient colors cannot be edited as vector.
color-light      Pure vector, small file (about 50 KB), simplified gradients. Use where an
                 embedded image is a problem (some PowerPoint and Word versions) or editing
                 gradients matters. Slightly less faithful shading.
ondark           For dark backgrounds: white "Pakaon", lighter blues in the fish.
white            One color, white. Best on blue backgrounds and photos.
navy             One color, navy. For print, stamps and fax.
mark-*           The fish and target ring only.
wordmark-color   The text only.

Made by tracing the supplied PNG, not from the original artwork file.
PNG folder: 2000 px wide, transparent background, one per SVG.
