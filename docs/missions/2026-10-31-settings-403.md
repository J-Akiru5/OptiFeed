## Built (feature/settings-tabs-403)

- `lib/settings/device-settings-tabs.ts`: tab ids, `?tab=` parsing, old-anchor-to-tab map, link builder, owner-scoped device selection.
- `components/settings/device-settings-tabs.tsx`: WAI-ARIA tablist (arrows, Home/End), panels stay mounted and are only hidden, tab kept in the URL with `history.replaceState`.
- `components/settings/device-switcher.tsx`: native select grouped by pond, status in each option; hidden with one feeder.
- `components/settings/unsaved-changes.tsx`: `useReportUnsavedChanges`, used by the daily cap, hopper, temperature and recalibration forms.
- Device settings page: device chosen from every feeder on the caller's ACTIVE ponds (was: first feeder of the active pond only).

**Deviation from the mockup:** switching tabs no longer asks Save/Discard. Panels stay mounted, so an edit survives a tab switch; the tab shows a dot instead. The dialog appears only when switching feeder (a navigation that would lose edits), and the browser prompt covers reload/close.

**Not covered:** the feed-rate calibration form (`DurationCalibrationForm`, a guided test flow) does not report unsaved edits; in-app links (sidebar) leave without a prompt because the App Router has no route-change event.
