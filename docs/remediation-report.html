What We Did — Detailed Breakdown

Security Fixes (Critical + High)

Finding #1 — .env Block in Pre-commit Hook

Added a guard in .husky/pre-commit that blocks commits containing .env files. Defense-in-depth layer on top of .gitignore.

Finding #2 — Hardcoded Device Token Removed

prisma/seed.ts previously had a hardcoded token. Replaced with a requireEnv("DEVICE_TOKEN") helper that reads from process.env and throws at startup if missing.

Finding #3 — Account Lockout System

Created a full lockout system: new UserLockout Prisma model, lib/auth/lockout.ts with recordFailedAttempt(), checkLockout(), resetLockout(). Updated login flow and added i18n keys for both English and Hiligaynon.

Finding #4 — Upstash Rate Limiting

Created lib/rate-limit.ts with two rate limiters: loginRateLimit (5 attempts/60s) and apiRateLimit (30 requests/60s). Applied to all 6 API endpoints. Dependencies: @upstash/ratelimit@2.0.8, @upstash/redis@1.38.2.

Finding #5 — withAuth Wrapper + CI Auth Check

Created lib/auth/with-auth.ts — a higher-order function wrapping API route handlers to verify sessions. Added CI workflow step scanning for auth checks with allowlist for token-authed routes.

Finding #6 — Ownership Validation

Added ownerId checks to settings.ts, time.ts, energy.ts (requestFeed, saveHopperCalibration, registerEnergyDevice), and notifications.ts (createDemoNotification).

Finding #7 — Security Headers

Added via next.config.ts: X-Content-Type-Options, X-Frame-Options, X-XSS-Protection, Referrer-Policy, Permissions-Policy, CSP.

Finding #8 — CORS Configuration

Added per-route CORS for /api/ingest, /api/feed-command, /api/schedule-sync.

Finding #10 — Error Sanitization

Removed details: String(error) from import/confirm response. Server returns generic "Import failed".

Finding #11 — Device API Error Handling

Wrapped feed-command and schedule-sync in try/catch with safe default responses.

Finding #12 — N+1 Fix

Replaced individual create() loops in import/confirm with createMany() for all 6 import types.

Finding #17 — Gemini Key Prefix Removed

Removed keyPrefix from geminiDebugInfo(). Debug output no longer includes any part of the API key.

Code Quality Fixes (Medium + Low)

Finding #14 — Health Check Endpoint

Created app/api/health/route.ts — runs SELECT 1 against DB, returns 503 on failure.

Finding #18 — Prompt Injection Protection

Three-layer defense: sanitizeInput() + enforcePromptLimit() in prompt.ts, pondName sanitization in context.ts, per-message 2000-char cap in chat/route.ts.

Finding #19 — Hardcoded User Data Replaced

Removed all hardcoded "Juan Miguel", "Jeff!", "ILO-POND-01", and pondPopulation = 5000. All now derived from session or constants.

Finding #21 — Shared Constants

Created lib/constants.ts with DEFAULT_FISH_COUNT, HOPPER_CAPACITY_KG, GRAMS_PER_FEEDING, EXPORT_ROW_LIMIT, MAX_PROMPT_LENGTH, PH_TZ.

Finding #22 — Export Query Row Limits

Added take: EXPORT_ROW_LIMIT (50,000) to all 12 queries in export routes.

Finding #23 — Database Indexes

Added via migration: Pond(ownerId), Notification(pondId, read), FcrReport(pondId, periodStart).

Finding #24 — Audit Cursor Fix

Changed cursor from createdAt to id (primary key, stable pagination).

Finding #27 — Chat History Cleared on Logout

Exposed clearMessages() from ChatWidgetProvider context. Both logout handlers call it.

Finding #28 — Error Boundaries

Created app/global-error.tsx + app/[locale]/(dashboard)/not-found.tsx.

Finding #29 — try/catch in Server Actions

Added try/catch to all unprotected server actions: notifications (3 functions), audit, biomass (all), schedule (toggleDevicePause).

Finding #30 — CSV Dynamic Typing Fix

Set dynamicTyping: false + type validation in lib/csv.ts. Filters rows with non-primitive values.
